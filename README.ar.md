# Notes

Notes هو تطبيق بسيط، محلي-أولاً، للملاحظات والمتابعات والروتينات/العادات والصفحات وتنظيم كانبان والتقارير وإعدادات الجهاز.

تُحفظ سجلاتك على هذا الجهاز افتراضيًا. لا يُرسل أي شيء إلى أي مكان إلا إذا اخترت إنشاء مفتاح مزامنة واستخدامه.

## الميزات

- عناصر لاحقًا / متابعات مع تواريخ
- روتينات وعادات، بما في ذلك العدادات والروتينات الموقوتة مدعومة بمؤقت داخلي
- صفحات وعناصر صفحات، بما في ذلك указатели к элементам Later
- لوحة kanban فوق مراجعات Later/Page
- مرفقات (وصف + بايتات محلية؛ البايتات تبقى محلية)
- سجل مشتق وتقارير نشاط الروتينات/العادات
- نسخ احتياطي واستعادة، ومزامنة مشفرة 선택ية
- تطبيق PWA قابل للتثبيت ويعمل بدون اتصال
- دمج الجهاز such as wake lock and notifications for timed routines

## التشغيل محليًا

```sh
npm ci
npm run build
npm run dev
```

ثم افتح http://127.0.0.1:8080.

المتطلبات:

- Node.js >= 20
- PHP >= 8.0 with pdo_sqlite and mbstring

## البيانات والخصوصية

تُخزن السجلات في IndexedDB لهذا المتصفح. لا يتضمن التطبيق تحليلات أو تتبعًا.

- `noteMedia` (بايتات المرفقات) محلية فقط، ولا تُزامن ولا تظهر في النسخ الاحتياطي.
- المزامنة اختيارية، معطلة افتراضيًا، ومشفّرة من طرف إلى طرف.
- الروتينات الموقوتة تستخدم دعم المؤقت الداخلي للتطبيق؛ لا توجد شاشة جلسات عامة افتراضيًا.
